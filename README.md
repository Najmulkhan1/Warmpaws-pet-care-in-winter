# 🐾 WarmPaws – Pet Care in Winter

## 🌟 Project Overview
**WarmPaws** is a cozy and friendly platform designed to help pet owners care for their furry friends during the chilly winter months.  
It offers users an easy way to explore **local pet care services**, **winter clothing options**, **grooming services**, and **expert pet care tips** — all through a simple, engaging interface.

## 🎯 Purpose
During winter, pets often need extra attention to stay comfortable and healthy.  
WarmPaws aims to:
- Educate pet owners with **expert winter care tips**.
- Connect them with **local grooming and vet services**.
- Provide access to **pet-friendly winter clothing** and **safety recommendations**.

---

## 🚀 Key Features
✅ User-friendly and responsive UI built with **React + TailwindCSS**  
✅ Browse and filter **winter pet care services**  
✅ View **detailed service descriptions** and **ratings**  
✅ Explore **categories** such as *Grooming, Clothing, Health, and Food*  
✅ Integrated with **fake JSON data** for testing and prototyping  
✅ Smooth navigation using **React Router DOM**  
✅ Styled with **DaisyUI** components for a clean and modern look  

---

## 🧩 Tech Stack
- **Frontend Framework:** React.js  
- **Styling:** Tailwind CSS + DaisyUI  
- **Routing:** React Router DOM  
- **Icons:** React Icons  
- **Data Source:** Static JSON (can be replaced with API later)
